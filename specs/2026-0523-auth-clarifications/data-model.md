## Domain Entities

### Entity: User (Aggregate Root)

**Purpose**: Represents an authenticated user in the system. Aggregate root that owns Email and Password value objects.

**Fields**:
| Field | Type | Required | Constraints | Notes |
|-------|------|----------|-------------|-------|
| `id` | UUID | Yes | Primary key, auto-generated by DB | Unique identifier, immutable |
| `email` | Email (VO) | Yes | Unique, RFC 5322 valid | Immutable once set |
| `password` | Password (VO) | Yes | Min 8 chars, 1 uppercase, 1 digit | Hashed, never plaintext |
| `created_at` | DateTime | Yes | Auto-set to now | Audit trail, immutable |
| `updated_at` | DateTime | No (future) | Not in this iteration | Reserved for future updates |

**Invariants** (Business Rules):
1. Email must be valid RFC 5322 format (enforced by Email VO)
2. Password must be strong (min 8 chars, 1 uppercase, 1 digit) — enforced by Password VO
3. Email must be unique across all users — enforced by DB UNIQUE constraint
4. Password is never stored in plaintext — enforced by Password VO + bcrypt
5. `id` is immutable (never changes after creation)
6. `created_at` is immutable (never changes after creation)

**State Transitions**:
```
[New User Object]
    ↓
[User.create(email, password)]  ← Validates email & password
    ↓
[User persisted in DB]  ← DB assigns final UUID
    ↓
[User can login]  ← Credentials verified against hash
```

**Example**:
```python
# Factory method (handles all validation)
user = User.create(email="john@example.com", password="SecurePass123")
# Returns User object with:
#   id = UUID (temp, will be replaced by DB)
#   email = Email("john@example.com")
#   password = Password(hash="$2b$12$...")  [plaintext never stored]
#   created_at = datetime.utcnow()

# Persist (BD generates final id)
saved_user = user_repo.create(user)  
# Returns user with id from DB
```

## Value Objects

### VO: Email

**Purpose**: Encapsulates email validation and uniqueness checks. Immutable.

**Definition**:
```python
class Email:
    """
    Value Object for email address.
    - Validates RFC 5322 format
    - Implements __eq__, __hash__ for use in collections
    - Immutable: once created, never changes
    """
    _value: str  # Immutable
    
    def __init__(self, value: str):
        if not self._is_valid(value):
            raise ValueError(f"Invalid email: {value}")
        self._value = value
    
    @staticmethod
    def _is_valid(email: str) -> bool:
        from email_validator import validate_email, EmailNotValidError
        try:
            validate_email(email)
            return True
        except EmailNotValidError:
            return False
    
    def __eq__(self, other) -> bool:
        return isinstance(other, Email) and self._value == other._value
    
    def __hash__(self) -> int:
        return hash(self._value)
    
    def __str__(self) -> str:
        return self._value
```

**Invariants**:
1. `_value` must be valid RFC 5322 email (checked in `__init__`)
2. Two Email objects are equal iff their values are equal
3. Email is hashable (can be used in sets, dicts)

**Validation Rules**:
- Format: RFC 5322 compliant (via email-validator)
- Uniqueness: Checked by UserRepository + DB constraint

### VO: Password

**Purpose**: Encapsulates password validation, hashing, and verification. Never exposed as plaintext.

**Definition**:
```python
class Password:
    """
    Value Object for password.
    - Validates password strength (min 8 chars, 1 uppercase, 1 digit)
    - Hashes plaintext using Strategy pattern (default: Bcrypt)
    - Immutable: once hashed, never changes
    - Never serialized or exposed
    """
    _hash: str  # Immutable, bcrypt hash
    
    def __init__(self, plaintext: str, strategy: HashingStrategy = None):
        if not self._is_strong(plaintext):
            raise ValueError("Password too weak (min 8 chars, 1 uppercase, 1 digit)")
        strategy = strategy or BcryptStrategy()
        self._hash = strategy.hash(plaintext)
    
    @staticmethod
    def _is_strong(password: str) -> bool:
        if len(password) < 8:
            return False
        if not any(c.isupper() for c in password):
            return False
        if not any(c.isdigit() for c in password):
            return False
        return True
    
    @property
    def hash(self) -> str:
        """Read-only hash, never the plaintext."""
        return self._hash
    
    def verify(self, plaintext: str, strategy: HashingStrategy = None) -> bool:
        """Check if plaintext matches stored hash."""
        strategy = strategy or BcryptStrategy()
        return strategy.verify(plaintext, self._hash)
```

**Invariants**:
1. Plaintext is never stored (immediately hashed)
2. Hash is immutable (never changes)
3. Verification is done via `verify(plaintext)`, never by exposing hash
4. Hash format is platform-specific (e.g., bcrypt's `$2b$12$...`)

**Validation Rules**:
- Strength: Min 8 chars, 1 uppercase, 1 digit (checked in `__init__`)
- Hashing: Via Strategy (bcrypt by default, extensible to argon2)

### Interface: IHashingStrategy

**Purpose**: Abstract contract for password hashing algorithms. Allows swapping bcrypt ↔ argon2 without domain changes.

**Methods**:

```python
class IHashingStrategy(ABC):
    @abstractmethod
    def hash(self, plaintext: str) -> str:
        """
        Hash plaintext password.
        
        Args:
            plaintext: Raw password (will be deleted after hashing)
        
        Returns:
            Hashed password string (safe to store)
        
        Raises:
            ValueError: If plaintext is invalid
        """
        pass
    
    @abstractmethod
    def verify(self, plaintext: str, hash: str) -> bool:
        """
        Verify plaintext against hash.
        
        Args:
            plaintext: User-provided password
            hash: Stored hash
        
        Returns:
            True if match, False otherwise
        """
        pass
```

**Implementations**:
1. `BcryptStrategy` (default, `infrastructure/security/bcrypt_strategy.py`)
2. `Argon2Strategy` (future, `infrastructure/security/argon2_strategy.py`)

## Database Schema

### Table: users

```sql
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);

-- Index for fast email lookups
CREATE INDEX idx_users_email ON users(email);

-- UNIQUE constraint prevents concurrent duplicate inserts
CREATE UNIQUE INDEX idx_users_email_unique ON users(email);
```

**Columns**:
| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `id` | UUID | PRIMARY KEY, auto-gen | User identity |
| `email` | VARCHAR(255) | UNIQUE, NOT NULL | Email address, searchable |
| `password_hash` | VARCHAR(255) | NOT NULL | Bcrypt hash ($2b$12$...), never plaintext |
| `created_at` | TIMESTAMP | NOT NULL, default now | Audit trail |

**Indexes**:
- `PRIMARY KEY (id)`: Fast lookup by user_id
- `UNIQUE INDEX (email)`: Prevents duplicates, enables fast search by email

**ACID Guarantees**:
- PostgreSQL ensures UNIQUE constraint is checked at transaction boundary
- If 2 requests try to insert same email concurrently, only 1 succeeds (SERIALIZABLE isolation)

## Validation Rules Summary

### Email Validation (RFC 5322)
- **Where**: Email VO (`domain/value_objects/email.py`)
- **How**: email-validator library
- **Triggers**: Thrown during User.create() if invalid
- **Error Type**: ValueError → maps to 400 Bad Request

### Password Strength Validation
- **Where**: Password VO (`domain/value_objects/password.py`)
- **Rules**:
  - Min 8 characters
  - At least 1 uppercase letter
  - At least 1 digit
- **Triggers**: Thrown during User.create() if weak
- **Error Type**: ValueError → maps to 400 Bad Request

### Email Uniqueness Validation
- **Where**: DB UNIQUE constraint + UserRepository.create()
- **How**: BD enforces at commit time; application catches IntegrityError
- **Triggers**: After successful User validation, during insert
- **Error Type**: IntegrityError (DB) → UserAlreadyExistsError (domain) → 409 Conflict

## Thread-Safety Analysis

| Component | Safety Mechanism | Why Safe |
|-----------|-----------------|----------|
| Email VO | Immutable | Once created, never changes. No shared state. |
| Password VO | Immutable | Hash never changes. Hashing is pure function. |
| User Entity | Immutable (in transaction) | ACID DB transactions ensure consistency. |
| IUserRepository | BD-enforced constraints | UNIQUE index prevents duplicates at transaction boundary. |
| Concurrent inserts | PostgreSQL SERIALIZABLE | Only 1 insert succeeds, others get IntegrityError. |

**Conclusion**: Thread-safety is achieved via:
1. **Immutability** of Value Objects (no shared mutable state)
2. **ACID transactions** in PostgreSQL (atomic, consistent writes)
3. **Constraint enforcement** at DB level (UNIQUE index)
4. **Connection pooling** (each request gets isolated connection)

## ORM Mapping (SQLAlchemy)

```python
# infrastructure/persistence/models.py
from sqlalchemy import Column, String, DateTime, Index
from sqlalchemy.ext.declarative import declarative_base
from datetime import datetime

Base = declarative_base()

class UserModel(Base):
    __tablename__ = "users"
    
    id = Column(String(36), primary_key=True)  # UUID as string for compatibility
    email = Column(String(255), unique=True, nullable=False, index=True)
    password_hash = Column(String(255), nullable=False)
    created_at = Column(DateTime, nullable=False, default=datetime.utcnow)
    
    __table_args__ = (
        Index('idx_users_email_unique', 'email', unique=True),
    )
    
    def to_domain(self) -> User:
        """Convert ORM model to domain entity."""
        return User(
            id=UUID(self.id),
            email=Email(self.email),
            password_hash=self.password_hash,  # Password VO reconstructed in repo
            created_at=self.created_at
        )
```
